Controllare un archivio prima di decomprimerlo, e verificare i checksum

Accanto al generatore, tfg ha piccoli strumenti per i file che hai già: se un archivio si può decomprimere in sicurezza, e se un file o un'intera cartella è ancora ciò che dice il suo checksum. Girano sulla tua macchina, senza upload e senza account.

La risposta breve

tfg tool archive-scan download.zip legge l'archivio senza decomprimere nulla e termina con il codice 0 se è sicuro, oppure 7 con l'elenco di ciò che ha trovato. tfg tool checksum setup.exe --expected <sum> dice se un file corrisponde al checksum che ti ha dato una pagina di download.

Archivi

Questo archivio si può decomprimere in sicurezza? Zip slip e zip bomb

archive-scan guarda dentro un file ZIP, TAR, TAR.GZ o gzip senza scrivere nulla su disco e dice se decomprimerlo è sicuro. Segnala:

  • una voce che verrebbe scritta fuori dalla cartella, la trappola nota come zip slip
  • un link, un dispositivo, o due nomi che finirebbero sullo stesso file
  • un nome che un sistema non può scrivere
  • una voce costruita per esplodere quando viene decompressa, la trappola nota come zip bomb
  • una voce danneggiata

Gli archivi dentro l'archivio, come uno ZIP in uno ZIP o un DOCX in un TAR, vengono letti allo stesso modo, in memoria, fino a 16 livelli di profondità. Una trappola in uno di essi è una trappola nell'insieme, perché un programma che decomprime tutto decomprime anche quelli. 

tfg tool archive-scan upload.zip
tfg tool archive-scan backup.tar.gz --unpacked_limit 500mb

--unpacked_limit segnala anche un archivio che, una volta decompresso, occupa più di quanto consenti. Un archivio sicuro termina con il codice 0 e qualsiasi problema trovato con 7, così una pipeline può fermarsi lì.

Un file

Questo file è davvero quello che dichiara di essere?

checksum calcola il checksum di un file e, se gliene dai uno da confrontare, dice se corrispondono. Supporta md5, sha1, sha256, sha512 e crc32, sha256 se non chiedi altro, e riconosce dalla lunghezza quale tipo di checksum gli hai dato. 

tfg tool checksum installer.msi
tfg tool checksum installer.msi --expected 9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08

Un checksum che non corrisponde termina con il codice 7. Risponde alla stessa domanda di Get-FileHash su Windows o di sha256sum su Linux, con il confronto già fatto per te.

Un'intera cartella

È cambiato qualcosa in questa cartella?

checksum-write scrive il checksum di ogni file di una cartella in un SHA256SUMS accanto ai file, con gli stessi byte che scrive sha256sum, e mai sopra uno già presente. checksum-check controlla poi ogni file elencato in SHA256SUMS. 

tfg tool checksum-write ./fixtures
tfg tool checksum-check ./fixtures/SHA256SUMS

I file che non elenca non vengono esaminati, come con sha256sum -c, e un percorso che esce dalla cartella viene rifiutato invece di essere letto. I file di esempio hanno un SHA256SUMS che puoi verificare in questo modo.
