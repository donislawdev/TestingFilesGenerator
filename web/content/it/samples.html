File di esempio per i test

File reali da scaricare per testare un modulo di upload, un parser o un'importazione: un file per ogni formato che questo generatore scrive, file rotti di proposito, tabelle come le esportano i fogli di calcolo e immagini segnaposto. Niente da installare e nessuna registrazione.

Prodotti da una sola ricetta

Tutti i file di questa pagina vengono da una sola ricetta, samples.yaml. Eseguila con tfg e ottieni gli stessi byte su qualsiasi macchina. Lo SHA-256 accanto a ogni file è quindi qualcosa che puoi verificare, invece di fidarti sulla parola. 

tfg generate samples.yaml --out samples

Tutti gli hash sono in SHA256SUMS. Mettilo in quella cartella, e tfg tool checksum-check samples/SHA256SUMS oppure sha256sum -c SHA256SUMS ti dice se ogni file corrisponde.

L'ultima colonna di ogni tabella è ciò che il manifest si aspetta che il tuo sistema faccia con il file. accept significa che deve accettarlo, reject che deve rifiutarlo, e unspecified che dipende dalle regole del tuo sistema.

Ogni formato

Un file per ogni formato, da 1 MB ciascuno

Documenti, immagini, testo, dati, archivi, posta, telemetria, audio e video, ognuno di esattamente 1 048 576 byte e ognuno un file reale del suo formato. Il PDF si apre in un lettore PDF, il DOCX in Word, l'XLSX in Excel e lo ZIP si decomprime. Il server invia compressi i file di testo e alcune immagini, quindi durante il download il tuo browser può mostrare una dimensione più piccola di quella della tabella. Il file salvato ha la dimensione della tabella e corrisponde al suo SHA-256.

Un'altra dimensione è un solo comando. tfg generate --format pdf --size 10mb scrive un PDF di esattamente 10 MB, e un file da 1 GB si fa allo stesso modo. File così grandi non sono tenuti su questa pagina, perché un comando li produce più in fretta di un download.

Rotti di proposito

File corrotti: PDF, Word, Excel, immagini, video e ZIP

Ognuno è stato prodotto sano e poi rotto, e pesa ancora esattamente 1 MB. truncate taglia la fine come fa un upload interrotto, e zero-head scrive zeri sui primi byte, dove un lettore guarda per capire che file è. Il manifest si aspetta che il tuo sistema li rifiuti tutti.

Per un'importazione

Tabelle CSV, JSON ed Excel

La stessa tabella scritta come la scrivono gli strumenti reali: con una virgola, un punto e virgola, una tabulazione o una barra verticale tra i valori, con fine riga di Windows, senza riga di intestazione, con ogni valore tra virgolette o nessuno, un CSV largo, un foglio Excel e JSON in tre layout. Alcuni sono marcati unspecified, perché accettare o no un punto e virgola è una scelta della tua importazione. Ciò che non deve fare è leggere metà della tabella.

Avanti

Dove andare da qui

  • Casi di test per l'upload di file dice quale di questi file verifica cosa in un modulo di upload.
  • I preset sono set pronti, ognuno per una domanda di test.
  • File di test in CI produce file come questi in una pipeline, invece di tenerli nel repository.
