Sample files for testing

Real files to download for testing an upload form, a parser or an import: one of every format this generator writes, files broken on purpose, tables the way spreadsheet programs export them, and placeholder pictures. Nothing to install and nothing to sign up for.

Made by one recipe

All {{ .Facts.SampleCount }} files come from one recipe, samples.yaml. Run it with tfg and you get the same bytes on any machine, so the SHA-256 beside each file is something you can check rather than take on trust. 

tfg generate samples.yaml --out samples

Every sum is in SHA256SUMS. Put it in that folder and tfg tool checksum-check samples/SHA256SUMS or sha256sum -c SHA256SUMS tells you whether every file matches.

The last column of each table is what the manifest expects your system to do with the file. accept means it should take the file, reject that it should turn the file away, and unspecified that it depends on the rules of your system.

Every format

One file of every format, 1 MB each

Documents, pictures, text, data, archives, mail, telemetry, sound and video, each exactly 1 048 576 bytes and each a real file of its format. The PDF opens in a PDF reader, the DOCX in Word, the XLSX in Excel and the ZIP extracts. The server sends text files and some pictures compressed, so while one of them downloads, your browser can show a smaller size than the table. The file it saves has the size in the table and matches its SHA-256.

Another size is one command. tfg generate --format pdf --size 10mb writes a PDF of exactly 10 MB, and a 1 GB file is made the same way. Files that large are not kept on this page, because a command makes them faster than a download.

Broken on purpose

Corrupt files: PDF, Word, Excel, pictures, video and ZIP

Each one was made healthy and then broken, and is still exactly 1 MB. truncate cuts the end off the way an interrupted upload does, and zero-head writes zeros over the first bytes, where a reader looks to see what the file is. The manifest expects your system to turn every one of them away.

Corrupt test files says how to make your own, in any format and at any size, and which damages there are.

For an import

CSV, JSON and Excel tables

The same table written the ways real tools write it: with a comma, a semicolon, a tab or a pipe between values, with Windows line endings, without a header row, with every value in quotes or none, a wide CSV, an Excel sheet and JSON in three layouts. Some are marked unspecified, because whether your import takes a semicolon is its own choice. What it must not do is read half of the table.

{{ with .SampleTable "tables" }}{{ template "samplesTable" . }}{{ end }}

They are the files of the tabular-import preset, which makes them with as many rows and columns as you ask for.

For a layout

Placeholder images in common sizes

A flat grey picture with its size written in the middle, for laying out a page before the real pictures exist: square thumbnails, a 300 by 250 ad, a 728 by 90 banner, a 1200 by 630 social card and a full HD screen. Each is as small as the picture can be.

{{ with .SampleTable "placeholders" }}{{ template "samplesTable" . }}{{ end }}

Any other size or colour:

tfg generate --format png --size smallest --set content=placeholder --set width=640 --set height=360 --set background=1e293b

The picture-sizes preset makes every size screens and platforms use in one run, with --content placeholder.
