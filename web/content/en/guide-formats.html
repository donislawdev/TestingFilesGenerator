Format settings

Every setting each format takes, with the values it accepts, its default and what it changes in the file. The list is read from the program when this page is built, in the program's own words: tfg formats <id> prints the same for one format.

How to give a setting

On the command line, --set takes one setting and repeats. In a recipe, the settings go under properties:

tfg generate --format pdf --size 1mb --set pages=20 --set page_size=letter --out ./pdf
targets:
  - id: report
    format: pdf
    size: 1mb
    properties:
      pages: 20
      page_size: letter

A setting left out takes its default. A value outside what the setting accepts is refused before anything is written, with the values that would work. Some settings also limit the smallest size a file can be, and a size below it is refused with the size that would work. The list of formats themselves, with the smallest file of each, is on Formats.
