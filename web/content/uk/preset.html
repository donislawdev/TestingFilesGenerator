Як його запустити?

Подивіться, скільки коштував би набір, зберіть його або візьміть його рецепт для правки:

tfg preset show {{ .ID }}
tfg generate --preset {{ .ID }}{{ range .Placeholders }} --{{ .Flag }} {{ .Default }}{{ end }} --out ./{{ .ID }}
tfg preset eject {{ .ID }} > {{ .ID }}.yaml
