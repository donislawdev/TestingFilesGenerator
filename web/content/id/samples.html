Contoh file untuk pengujian

File sungguhan untuk diunduh, untuk menguji formulir unggah, parser, atau impor: satu file dari setiap format yang ditulis generator ini, file yang sengaja dirusak, tabel seperti yang diekspor program spreadsheet, dan gambar placeholder. Tanpa instalasi dan tanpa pendaftaran.

Dari satu resep

Semua file di halaman ini berasal dari satu resep, samples.yaml. Jalankan dengan tfg dan Anda mendapat byte yang sama di mesin mana pun, sehingga SHA-256 di samping setiap file bisa Anda periksa sendiri, bukan sekadar dipercaya. 

tfg generate samples.yaml --out samples

Semua checksum ada di SHA256SUMS. Taruh file itu di folder tersebut, lalu tfg tool checksum-check samples/SHA256SUMS atau sha256sum -c SHA256SUMS memberi tahu apakah setiap file cocok.

Kolom terakhir setiap tabel adalah apa yang diharapkan manifes dari sistem Anda terhadap file itu. accept berarti sistem harus menerima file, reject berarti harus menolaknya, dan unspecified berarti tergantung pada aturan sistem Anda.

Setiap format

Satu file dari setiap format, masing-masing 1 MB

Dokumen, gambar, teks, data, arsip, e-mail, telemetri, audio, dan video, masing-masing tepat 1 048 576 byte dan masing-masing file asli dari formatnya. PDF terbuka di pembaca PDF, DOCX di Word, XLSX di Excel, dan ZIP bisa diekstrak.

Ukuran lain cukup satu perintah. tfg generate --format pdf --size 10mb menulis PDF berukuran tepat 10 MB, dan file 1 GB dibuat dengan cara yang sama. File sebesar itu tidak disimpan di halaman ini, karena perintah membuatnya lebih cepat daripada mengunduhnya.

Sengaja dirusak

File rusak: PDF, Word, Excel, gambar, video, dan ZIP

Setiap file dibuat sehat lalu dirusak, dan tetap berukuran tepat 1 MB. truncate memotong ujung file seperti yang dilakukan unggahan yang terputus, dan zero-head menimpa byte pertama dengan nol, yaitu bagian yang dilihat pembaca untuk mengetahui jenis file itu. Manifes mengharapkan sistem Anda menolak semuanya.

Untuk impor

Tabel CSV, JSON, dan Excel

Tabel yang sama ditulis dengan cara alat sungguhan menulisnya: dengan koma, titik koma, tab, atau garis tegak di antara nilai, dengan akhir baris Windows, tanpa baris header, dengan setiap nilai dalam tanda kutip atau tanpa kutip sama sekali, CSV yang lebar, sheet Excel, dan JSON dalam tiga tata letak. Sebagian ditandai unspecified, karena apakah impor Anda menerima titik koma adalah pilihannya sendiri. Yang tidak boleh terjadi adalah impor hanya membaca separuh tabel.

Untuk tata letak

Gambar placeholder dalam ukuran umum

Gambar abu-abu polos dengan ukurannya tertulis di tengah, untuk menata halaman sebelum gambar aslinya ada: thumbnail persegi, iklan 300 x 250, banner 728 x 90, kartu media sosial 1200 x 630, dan layar Full HD. Masing-masing sekecil yang dimungkinkan untuk gambar itu.

Ukuran atau warna lain apa pun:

tfg generate --format png --size smallest --set content=placeholder --set width=640 --set height=360 --set background=1e293b

Preset picture-sizes membuat setiap ukuran yang dipakai layar dan platform dalam satu proses, dengan --content placeholder.

Berikutnya

Ke mana dari sini

  • Kasus uji unggah file menjelaskan file mana yang menguji apa pada formulir unggah.
  • Preset adalah set siap pakai, masing-masing untuk satu pertanyaan pengujian.
  • File uji di CI membuat file seperti ini di pipeline alih-alih menyimpannya di repositori.
