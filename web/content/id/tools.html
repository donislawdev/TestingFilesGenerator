Periksa arsip sebelum diekstrak, dan verifikasi checksum

Selain generator, tfg punya alat kecil untuk file yang sudah Anda miliki: apakah arsip aman diekstrak, dan apakah sebuah file atau seluruh folder masih sesuai dengan checksum-nya. Alat ini berjalan di mesin Anda, tanpa unggahan dan tanpa akun.

Jawaban singkat

tfg tool archive-scan download.zip membaca arsip tanpa mengekstrak apa pun dan berakhir dengan kode 0 jika aman, atau 7 dengan daftar yang ditemukannya. tfg tool checksum setup.exe --expected <sum> memberi tahu apakah file cocok dengan checksum yang diberikan halaman unduhan.

Yang tersedia

Alat apa saja yang ada?

Ini daftar yang dicetak program, dibaca darinya saat halaman ini dibangun. tfg tool list mencetak hal yang sama, dan tfg tool show <id> menjelaskan apa yang diterima salah satunya. Setiap alat juga ada di layar Tools pada jendela program, dengan pengaturan yang sama.

Arsip

Apakah arsip ini aman diekstrak? Zip slip dan zip bomb

archive-scan melihat isi file ZIP, TAR, TAR.GZ, atau gzip tanpa menulis apa pun ke disk dan menyatakan apakah aman mengekstraknya. Alat ini melaporkan:

  • entri yang akan ditulis di luar folder, jebakan yang dikenal sebagai zip slip
  • link, perangkat, atau dua nama yang akan berakhir di satu file
  • nama yang tidak bisa ditulis oleh sistem
  • entri yang dibuat untuk meledak saat diekstrak, jebakan yang dikenal sebagai zip bomb
  • entri yang rusak

Arsip di dalam arsip, seperti ZIP di dalam ZIP atau DOCX di dalam TAR, dibaca dengan cara yang sama, di memori, sampai kedalaman 16 tingkat. Jebakan di salah satunya adalah jebakan bagi keseluruhan, karena program yang mengekstrak semuanya juga mengekstrak arsip-arsip itu. 

tfg tool archive-scan upload.zip
tfg tool archive-scan backup.tar.gz --unpacked_limit 500mb

--unpacked_limit juga melaporkan arsip yang hasil ekstraknya lebih besar dari yang Anda izinkan. Hasil aman berakhir dengan kode 0, dan setiap temuan berakhir dengan 7, sehingga pipeline bisa berhenti karenanya.

Satu file

Apakah file ini benar file yang diakuinya?

checksum menghitung checksum sebuah file dan, jika diberi checksum pembanding, menyatakan apakah keduanya cocok. Alat ini menerima md5, sha1, sha256, sha512, dan crc32, sha256 jika Anda tidak meminta yang lain, dan mengenali jenis checksum yang diberikan dari panjangnya. 

tfg tool checksum installer.msi
tfg tool checksum installer.msi --expected 9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08

Checksum yang tidak cocok berakhir dengan kode 7. Ini menjawab pertanyaan yang sama dengan Get-FileHash di Windows atau sha256sum di Linux, dengan perbandingan yang dilakukan untuk Anda.

Seluruh folder

Apakah ada yang berubah di folder ini?

checksum-write menulis checksum setiap file dalam folder ke SHA256SUMS di sebelahnya, dengan byte yang sama seperti yang ditulis sha256sum, dan tidak pernah menimpa file yang sudah ada. checksum-check kemudian memeriksa setiap file yang tercantum di SHA256SUMS. 

tfg tool checksum-write ./fixtures
tfg tool checksum-check ./fixtures/SHA256SUMS

File yang tidak tercantum tidak diperiksa, sama seperti sha256sum -c, dan path yang keluar dari folder ditolak alih-alih dibaca. Contoh file disertai SHA256SUMS yang bisa Anda periksa dengan cara ini.

  • Dokumentasi memuat setiap perintah dan kode keluar.
