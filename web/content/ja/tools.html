展開する前にアーカイブを検査し、チェックサムを確認する

tfgには、生成ツールのほかに、手元にあるファイル向けの小さなツールがあります。アーカイブを安全に展開できるか、ファイルやフォルダー全体がチェックサムのとおりのままかを確かめます。どれも自分のマシンで動き、アップロードもアカウントも不要です。

短い答え

tfg tool archive-scan download.zipは、何も展開せずにアーカイブを読み、安全ならコード0で、そうでなければ見つかったものの一覧とともにコード7で終了します。tfg tool checksum setup.exe --expected <sum>は、ファイルがダウンロードページに書かれたチェックサムと一致するかを示します。

アーカイブ

このアーカイブは安全に展開できますか。zip slipとzip爆弾

archive-scanは、ディスクに何も書き込まずにZIP、TAR、TAR.GZ、gzipファイルの中を調べ、展開しても安全かを示します。報告するものは次のとおりです。

  • フォルダーの外に書き込まれるエントリ。zip slipと呼ばれる罠です
  • リンク、デバイス、または同じ1つのファイルに書き込まれることになる2つの名前
  • システムが書き込めない名前
  • 展開すると爆発的に大きくなるように作られたエントリ。zip爆弾と呼ばれる罠です
  • 破損したエントリ

ZIPの中のZIPやTARの中のDOCXのような、アーカイブの中のアーカイブも、同じようにメモリ内で16階層まで読みます。その1つにある罠はアーカイブ全体の罠です。すべてを展開するプログラムは、それらも展開するからです。 

tfg tool archive-scan upload.zip
tfg tool archive-scan backup.tar.gz --unpacked_limit 500mb

--unpacked_limitを指定すると、展開後のサイズが許容量を超えるアーカイブも報告します。安全ならコード0、何か見つかればコード7で終了するので、パイプラインはそこで止められます。

1つのファイル

このファイルは、名乗っているとおりのファイルですか。

checksumはファイルのチェックサムを計算し、比較する値を渡せば一致するかどうかを示します。md5、sha1、sha256、sha512、crc32に対応し、指定しなければsha256を使います。渡された値がどの種類かは、その長さから判断します。 

tfg tool checksum installer.msi
tfg tool checksum installer.msi --expected 9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08

一致しないチェックサムはコード7で終了します。WindowsのGet-FileHashやLinuxのsha256sumと同じ問いに答えますが、比較まで自動で行います。

フォルダー全体

このフォルダーの中で何か変わりましたか。

checksum-writeは、フォルダー内のすべてのファイルのチェックサムを、その横のSHA256SUMSに書き込みます。sha256sumが書くのと同じバイトで、既存のSHA256SUMSを上書きすることはありません。checksum-checkは、後でSHA256SUMSに載っているすべてのファイルを確認します。 

tfg tool checksum-write ./fixtures
tfg tool checksum-check ./fixtures/SHA256SUMS

載っていないファイルはsha256sum -cと同じく確認しません。フォルダーの外に出るパスは、読まずに拒否します。サンプルファイルには、この方法で確認できるSHA256SUMSが付いています。
