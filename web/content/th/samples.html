ไฟล์ตัวอย่างสำหรับทดสอบ

ไฟล์จริงให้ดาวน์โหลดสำหรับทดสอบฟอร์มอัปโหลด ตัวแยกวิเคราะห์ หรือการนำเข้า: ทุกรูปแบบที่ตัวสร้างนี้เขียนได้ รูปแบบละหนึ่งไฟล์ ไฟล์ที่ตั้งใจทำให้เสีย ตารางแบบที่โปรแกรมสเปรดชีตส่งออก และภาพตัวยึดตำแหน่ง ไม่ต้องติดตั้งอะไรและไม่ต้องสมัครสมาชิก

สร้างจากสูตรเดียว

ทุกไฟล์ในหน้านี้มาจากสูตรเดียวคือ samples.yaml รันด้วย tfg แล้วคุณจะได้ไบต์เดียวกันบนทุกเครื่อง ค่า SHA-256 ข้างแต่ละไฟล์จึงเป็นสิ่งที่คุณตรวจสอบเองได้ ไม่ต้องเชื่อตามคำบอก 

tfg generate samples.yaml --out samples

เช็กซัมทั้งหมดอยู่ใน SHA256SUMS วางไฟล์นี้ไว้ในโฟลเดอร์นั้น แล้ว tfg tool checksum-check samples/SHA256SUMS หรือ sha256sum -c SHA256SUMS จะบอกว่าทุกไฟล์ตรงกันหรือไม่

คอลัมน์สุดท้ายของแต่ละตารางคือสิ่งที่แมนิเฟสต์คาดหวังให้ระบบของคุณทำกับไฟล์นั้น accept หมายความว่าระบบควรรับไฟล์ reject หมายความว่าควรปฏิเสธไฟล์ และ unspecified หมายความว่าขึ้นอยู่กับกฎของระบบของคุณ

ทุกรูปแบบ

ทุกรูปแบบ รูปแบบละหนึ่งไฟล์ ไฟล์ละ 1 MB

เอกสาร รูปภาพ ข้อความ ข้อมูล ไฟล์บีบอัด อีเมล เทเลเมทรี เสียง และวิดีโอ แต่ละไฟล์มีขนาด 1 048 576 ไบต์พอดี และแต่ละไฟล์เป็นไฟล์จริงของรูปแบบนั้น ไฟล์ PDF เปิดได้ในโปรแกรมอ่าน PDF ไฟล์ DOCX เปิดใน Word ไฟล์ XLSX เปิดใน Excel และไฟล์ ZIP แตกไฟล์ได้ เซิร์ฟเวอร์ส่งไฟล์ข้อความและรูปภาพบางไฟล์แบบบีบอัด ระหว่างดาวน์โหลดเบราว์เซอร์จึงอาจแสดงขนาดที่เล็กกว่าในตาราง ไฟล์ที่บันทึกแล้วมีขนาดตามตารางและตรงกับค่า SHA-256 ของไฟล์นั้น

ขนาดอื่นใช้คำสั่งเดียว tfg generate --format pdf --size 10mb เขียน PDF ขนาด 10 MB พอดี และไฟล์ 1 GB ก็สร้างแบบเดียวกัน หน้านี้ไม่เก็บไฟล์ใหญ่ขนาดนั้น เพราะคำสั่งสร้างไฟล์ได้เร็วกว่าการดาวน์โหลด

ตั้งใจทำให้เสีย

ไฟล์ PDF, Word, Excel ที่เสียหาย รวมถึงรูปภาพ วิดีโอ และ ZIP

แต่ละไฟล์สร้างขึ้นแบบปกติก่อนแล้วจึงทำให้เสีย และยังมีขนาด 1 MB พอดี truncate ตัดส่วนท้ายทิ้งเหมือนที่การอัปโหลดที่ถูกขัดจังหวะทิ้งไว้ และ zero-head เขียนศูนย์ทับไบต์แรกๆ ซึ่งเป็นจุดที่ตัวอ่านดูว่าไฟล์คืออะไร แมนิเฟสต์คาดหวังให้ระบบของคุณปฏิเสธทุกไฟล์

สำหรับการนำเข้า

ตาราง CSV, JSON และ Excel

ตารางเดียวกันที่เขียนในแบบที่เครื่องมือจริงเขียน: คั่นค่าด้วยจุลภาค อัฒภาค แท็บ หรือขีดตั้ง ใช้การขึ้นบรรทัดแบบ Windows ไม่มีแถวหัวตาราง ใส่เครื่องหมายคำพูดทุกค่าหรือไม่ใส่เลย CSV แบบกว้าง แผ่นงาน Excel และ JSON สามแบบการจัดวาง บางไฟล์มีป้าย unspecified เพราะการนำเข้าของคุณจะรับอัฒภาคหรือไม่เป็นทางเลือกของมันเอง สิ่งที่มันต้องไม่ทำคืออ่านตารางได้แค่ครึ่งเดียว

ภาพตัวยึดตำแหน่งในขนาดที่ใช้บ่อย

ภาพสีเทาเรียบที่มีขนาดของตัวเองเขียนอยู่ตรงกลาง สำหรับจัดหน้าก่อนที่จะมีรูปจริง: ภาพย่อสี่เหลี่ยมจัตุรัส โฆษณา 300 x 250 แบนเนอร์ 728 x 90 การ์ดโซเชียล 1200 x 630 และหน้าจอ Full HD แต่ละภาพเล็กที่สุดเท่าที่ภาพนั้นจะเล็กได้

ถัดไป

จากตรงนี้ไปไหนต่อ

  • กรณีทดสอบการอัปโหลดไฟล์ บอกว่าไฟล์ไหนในนี้ทดสอบอะไรในฟอร์มอัปโหลด
  • พรีเซ็ต คือชุดสำเร็จรูป แต่ละชุดสำหรับคำถามการทดสอบข้อเดียว
  • ไฟล์ทดสอบใน CI สร้างไฟล์แบบนี้ในไปป์ไลน์แทนการเก็บไว้ในรีโพซิทอรี
