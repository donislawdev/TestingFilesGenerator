Ein Archiv vor dem Entpacken prüfen und Prüfsummen abgleichen

Neben dem Generator hat tfg kleine Werkzeuge für Dateien, die du schon hast: ob sich ein Archiv sicher entpacken lässt und ob eine Datei oder ein ganzer Ordner noch das ist, was seine Prüfsumme sagt. Sie laufen auf deinem Rechner, ohne Upload und ohne Konto.

Die kurze Antwort

tfg tool archive-scan download.zip liest das Archiv, ohne etwas zu entpacken, und endet mit Code 0, wenn es sicher ist, oder mit 7 und einer Liste dessen, was es gefunden hat. tfg tool checksum setup.exe --expected <sum> sagt, ob eine Datei zu der Summe passt, die dir eine Download-Seite genannt hat.

Was es gibt

Welche Werkzeuge gibt es?

Das ist die Liste, die das Programm ausgibt, beim Erstellen dieser Seite aus ihm gelesen. tfg tool list gibt dieselbe aus, und tfg tool show <id> sagt, was eines davon annimmt. Jedes Werkzeug gibt es auch im Desktop-Fenster auf dem Bildschirm Tools, mit denselben Einstellungen.

Archive

Lässt sich dieses Archiv sicher entpacken? Zip Slip und Zip-Bomben

archive-scan schaut in eine ZIP-, TAR-, TAR.GZ- oder gzip-Datei, ohne etwas auf die Festplatte zu schreiben, und sagt, ob das Entpacken sicher ist. Es meldet:

  • einen Eintrag, der außerhalb des Ordners geschrieben würde, die als Zip Slip bekannte Falle
  • einen Link, ein Gerät oder zwei Namen, die in derselben Datei landen würden
  • einen Namen, den ein System nicht schreiben kann
  • einen Eintrag, der so gebaut ist, dass er beim Entpacken explodiert, die als Zip-Bombe bekannte Falle
  • einen beschädigten Eintrag

Archive im Archiv, etwa ein ZIP in einem ZIP oder eine DOCX in einem TAR, werden genauso gelesen, im Speicher, bis zu 16 Ebenen tief. Eine Falle in einem davon ist eine Falle im Ganzen, denn ein Programm, das alles entpackt, entpackt auch diese. 

tfg tool archive-scan upload.zip
tfg tool archive-scan backup.tar.gz --unpacked_limit 500mb

--unpacked_limit meldet außerdem ein Archiv, das entpackt mehr belegt, als du erlaubst. Sicher endet mit Code 0, jeder Fund mit 7, sodass eine Pipeline daran anhalten kann.

Eine Datei

Ist diese Datei die, die sie zu sein vorgibt?

checksum berechnet die Prüfsumme einer Datei und sagt, wenn du eine zum Vergleich angibst, ob beide übereinstimmen. Es kennt md5, sha1, sha256, sha512 und crc32, sha256, wenn du nichts anderes verlangst, und erkennt an der Länge, welche Art von Summe du angegeben hast. 

tfg tool checksum installer.msi
tfg tool checksum installer.msi --expected 9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08

Eine Summe, die nicht passt, endet mit Code 7. Es beantwortet dieselbe Frage wie Get-FileHash unter Windows oder sha256sum unter Linux, nur dass der Vergleich für dich erledigt wird.

Ein ganzer Ordner

Hat sich in diesem Ordner etwas geändert?

checksum-write schreibt die Prüfsumme jeder Datei eines Ordners in eine SHA256SUMS daneben, mit denselben Bytes, die sha256sum schreibt, und nie über eine, die schon da ist. checksum-check prüft später jede Datei, die SHA256SUMS auflistet. 

tfg tool checksum-write ./fixtures
tfg tool checksum-check ./fixtures/SHA256SUMS

Dateien, die dort nicht aufgelistet sind, werden nicht angesehen, genau wie bei sha256sum -c, und ein Pfad, der den Ordner verlässt, wird abgewiesen statt gelesen. Die Beispieldateien kommen mit einer SHA256SUMS, die du so prüfen kannst.
