Dokumentasi

Cara memasang tfg, membuat berkas uji pertama Anda, dan semua yang diterima dan ditulis program: setiap perintah dan setiap opsi, setiap kunci resep, setiap bidang manifes, dan setiap pengaturan setiap format. Halaman-halaman ini berbahasa Inggris, karena dibuat dari program itu sendiri setiap kali situs dibangun, sehingga selalu sesuai dengan versi yang Anda unduh.

Halaman dokumentasi

  • Pemasangan EN

    Unduh untuk Windows, macOS, atau Linux, periksa arsipnya, atau pasang dengan Docker, npm, pip, atau Go.

  • Memulai EN

    Berkas pertama dengan ukuran tepat, lalu sepuluh ribu, diperiksa, dihapus, dan ditulis sebagai resep.

  • Perintah EN

    Setiap perintah dan setiap opsi beserta nilai bawaannya, dan semua kode keluar.

  • Menulis resep EN

    Setiap kunci resep, ukuran, nama berkas, reaksi yang diharapkan, kerusakan, arsip, dan preset.

  • Galeri resep EN

    Resep siap unduh untuk unggahan, impor, arsip, email, media, CI, dan berkas massal.

  • Manifes EN

    Setiap bidang manifest.json dan cara tes membacanya.

  • Pengaturan format EN

    Setiap pengaturan setiap format, dengan nilai yang diterima dan nilai bawaannya.

  • Framework pengujian EN

    Berkas di dalam pytest, Playwright, Vitest, dan node:test.

  • Aplikasi desktop EN

    Jendela program, layar demi layar.

  • Alat

    Alat offline untuk file yang sudah Anda miliki: periksa apakah arsip aman diekstrak, termasuk zip slip dan zip bomb, serta periksa atau tulis checksum SHA-256.

Apa yang dilakukan alat ini, per topik

  • Format

    Semua format file yang dihasilkan, file terkecil yang mungkin untuk tiap format, dan pengaturan yang diterimanya. Semua 32 terbuka di aplikasi aslinya.

  • Preset

    Set file uji siap pakai, masing-masing menjawab satu pertanyaan pengujian: batas unggahan, nama file, enkoding, impor tabel, file kosong, dan validasi.

  • File rusak

    File yang sengaja dirusak, berukuran tepat, dengan manifes yang menyatakan sistem Anda harus menolaknya. Untuk menguji validasi unggahan dan parser.

  • Contoh file

    Unduh contoh file untuk pengujian: satu file 1 MB per format, PDF, Word, dan Excel yang rusak, tabel CSV, dan gambar placeholder, masing-masing dengan SHA-256.

  • Kasus uji unggah

    Kasus uji untuk unggah file: batas ukuran, file kosong dan rusak, tipe yang salah, nama file tak terduga, dan arsip, masing-masing dengan file yang mengujinya.

  • File uji di CI

    Buat file uji di pipeline alih-alih meng-commit biner: workflow GitHub Actions, job GitLab, kode keluar, dan jebakan PowerShell.

  • Ukuran Tepat

    fsutil, dd, truncate, dan mkfile, masing-masing diukur di sistemnya, dan mengapa file yang dibuat begitu bukan PDF atau PNG saat pengujian membutuhkannya.

Masih buntu?

tfg <command> --help menunjukkan di terminal apa yang diterima sebuah perintah. Setiap penolakan menyebut pengaturan yang dimaksud, alasannya, dan nilai yang akan berhasil. Jika sesuatu tidak berperilaku seperti yang dikatakan halaman ini, laporkan. Itu kesalahan halaman atau program.
