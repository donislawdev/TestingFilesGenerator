Preset

Ukuran gambar

Apakah sistem saya menerima gambar dalam ukuran yang dipakai layar dan platform?

Preset picture-sizes membuat satu set lengkap file uji asli untuk pertanyaan ini dengan satu perintah, dan manifest.json di sampingnya yang menyatakan bagaimana sistem Anda harus bereaksi terhadap tiap file. Semua di bawah dibaca dari program, pada nilai bawaan versi ini.

Apa yang biasanya ditemukan?

  • batas lebar atau tinggi yang dibuat untuk satu bentuk dan menolak bentuk lain, misalnya latar profil selebar 1584 px
  • thumbnail terpotong atau tergencet karena kode mengharapkan gambar mendatar dan yang datang gambar tegak
  • gambar dengan tinggi ganjil, misalnya 1200 x 627, ditolak oleh langkah yang hanya menerima ukuran genap
  • gambar 4K yang kehabisan waktu atau memori dalam perjalanan menjadi thumbnail, padahal filenya sendiri kecil

Apa isi set?

Pada nilai bawaan, seperti yang dilaporkan tfg preset show picture-sizes:

File21
Target dalam resepnya21
Ukuran total4 178 420 B
Formatjpg

Dan apa yang diharapkan manifes set itu dari sistem Anda:

DiharapkanArtiFile
acceptSistem Anda harus menerima file ini.21

Apa yang dapat Anda ubah?

PengaturanMenerimaBawaanFungsinya
--groups nama grup dipisahkan koma, atau all all Ukuran yang ada di set: screens untuk ukuran layar, avatars untuk foto profil, dan social untuk sampul, banner, postingan, dan thumbnail. Biarkan all untuk semuanya.
--content placeholder, test test Apa yang ditampilkan gambar. Pola uji dipakai untuk memeriksa cara file dibaca. Placeholder adalah warna polos dengan tulisan di tengah, untuk menata halaman sebelum gambar aslinya ada.
--format id format dari halaman format jpg Format setiap file dalam set. Ini adalah opsi alat itu sendiri, dan preset hanya memberinya nilai bawaan.

Bagaimana menjalankannya?

Lihat biaya set, buat, atau ambil resepnya untuk disunting:

tfg preset show picture-sizes
tfg generate --preset picture-sizes --out ./picture-sizes
tfg preset eject picture-sizes > picture-sizes.yaml

Atau bangun di atasnya dalam resep Anda sendiri, di samping pengujian Anda:

version: 1
extends: preset:picture-sizes
