Recipe gallery

Ready recipes for test sets people build again and again. Download one, run it, and change it to fit your system. Each is a short YAML file with a comment on every part, and each writes into a folder of its own name, so several can run one after another.

How to use one

Download the file, then run tfg generate image-upload.yaml. The files and the manifest land in ./image-upload. Change a limit, a size or a count in the file, and tfg validate image-upload.yaml checks it before anything is written.

Recipes for common tests

Every preset as a recipe

A preset is a recipe with a name. These are the recipes the presets stand for, as tfg preset eject prints them with their default settings. They name no output folder, so give them one with --out. Each preset has a page of its own with what it finds and every setting it takes.

PresetThe question it answersFilesBytes
empty-and-minimal.yaml
Empty and minimal		 Does a file that is valid and as small as the format allows get through? 34 41 762
filename-handling.yaml
File name handling		 Will my system store, show and give back a file name it did not expect? 50 51 200
picture-sizes.yaml
Picture sizes		 Does my system take pictures at the sizes screens and platforms use? 21 4 178 420
size-boundaries.yaml
Size boundaries		 Is a size limit enforced exactly where it is declared? 7 73 400 320
tabular-import.yaml
Tabular import		 Does my table import survive what real tools export? 13 3 080 060
text-encoding.yaml
Text encoding		 Does my reader know which encoding a file is in, or is it guessing? 20 81 920
upload-validation.yaml
Upload validation		 Does my upload form take what it should and turn the rest away? 75 120 655 872 
tfg generate size-boundaries.yaml --out ./size-boundaries

Write your own

Every key a recipe takes is in the recipe reference, and every setting of every format in Format settings. A recipe can also start from a preset with extends, as the image, document and media recipes here do, and add its own files after the set of the preset.
