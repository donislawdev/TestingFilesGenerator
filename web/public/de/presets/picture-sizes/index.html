Presets

Bildgrößen

Nimmt mein System Bilder in den Größen an, die Bildschirme und Plattformen verwenden?

Das Preset picture-sizes baut mit einem Befehl ein ganzes Set echter Testdateien für diese Frage und ein manifest.json daneben, das beschreibt, wie dein System auf jede Datei reagieren soll. Alles unten wird aus dem Programm gelesen, mit den Standardwerten dieser Version.

Was findet es meistens?

  • eine Grenze für Breite oder Höhe, die für eine Bildform gedacht war und eine andere abweist, etwa einen Profilhintergrund mit 1584 px Breite
  • ein Vorschaubild, das beschnitten oder gestaucht wird, weil der Code ein Querformat erwartet und ein Hochformat ankommt
  • ein Bild mit ungerader Höhe, etwa 1200 x 627, das von einem Schritt abgewiesen wird, der nur gerade Größen annimmt
  • ein 4K-Bild, dem auf dem Weg zum Vorschaubild Zeit oder Speicher ausgeht, obwohl die Datei selbst klein ist

Was steckt im Set?

Mit den Standardwerten, wie es tfg preset show picture-sizes ausgibt:

Dateien21
Targets in seinem Rezept21
Gesamtgröße4 178 420 B
Formatejpg

Und was das Manifest dieses Sets von deinem System erwartet:

ErwartetBedeutungDateien
acceptDein System soll die Datei annehmen.21

Was kannst du ändern?

EinstellungNimmtStandardWas es tut
--groups Gruppennamen, durch Kommas getrennt, oder all all Welche Größen das Set enthält: screens für Bildschirmgrößen, avatars für Profilbilder und social für Titelbilder, Banner, Beiträge und Vorschaubilder. Mit all bekommst du alle.
--content placeholder, test test Was das Bild zeigt. Ein Testmuster dient dazu, zu prüfen, wie eine Datei gelesen wird. Ein Platzhalter ist eine einfarbige Fläche mit Text in der Mitte, um eine Seite zu gestalten, bevor es die echten Bilder gibt.
--format eine Format-ID von der Formate-Seite jpg Das Format jeder Datei im Set. Es ist ein Flag des Tools selbst, das Preset gibt ihm nur einen Standardwert.

Wie führst du es aus?

Sieh nach, was das Set kosten würde, baue es oder nimm sein Rezept zum Bearbeiten:

tfg preset show picture-sizes
tfg generate --preset picture-sizes --out ./picture-sizes
tfg preset eject picture-sizes > picture-sizes.yaml

Oder baue in einem eigenen Rezept darauf auf, neben deinen Tests:

version: 1
extends: preset:picture-sizes
