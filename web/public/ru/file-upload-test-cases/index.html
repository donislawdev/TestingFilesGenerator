Сценарии

Тест-кейсы для загрузки файлов и файлы для их запуска

Чек-лист тест-кейсов для загрузки файлов, от лимита размера до имени файла, которое пытается выйти из своей папки. Для каждого кейса указан файл, который его проверяет, и то, что ваша система должна с ним сделать, так что список можно запустить, а не только прочитать.

Весь список одной командой

tfg generate --preset upload-validation --limit 10mb --allow jpg,png,pdf --out ./upload записывает файл почти для каждого кейса ниже вместе с манифестом, в котором сказано, что должно произойти с каждым из них. Укажите лимит и типы, которые объявляет ваша форма.

accept означает, что ваша система должна принять файл, а reject - что она должна отклонить его с понятным сообщением. unspecified означает, что верным может быть любой ответ, поэтому запишите, какой из них выбирает ваша система, и проверяйте, что она поступает так каждый раз. Слово после результата - это причина, которую указывает манифест.

Размер

Применяется ли лимит размера там, где он объявлен?

Тест-кейсФайлОжидается
На байт меньше лимита10mb_under_1b.jpgaccept
Ровно по лимиту10mb_at_limit.jpgaccept
На байт больше лимита10mb_over_1b.jpgreject size_limit
Вдвое больше лимита, чтобы убедиться, что сервер прекращает чтение рано, а не загружает всё в память10mb_far_over_2x.jpgreject size_limit
Пустой файл размером 0 байтempty.jpgunspecified size_zero

Чаще всего лимит ошибается в двух случаях: когда он проверяется только в браузере и когда он считается в МБ там, где код считает МиБ. Пресет size-boundaries кладёт файл на каждом расстоянии от выбранного вами лимита: байт, килобайт и мегабайт в обе стороны.

Тип

Принимает ли форма нужные типы и отклоняет ли остальные?

Тест-кейсФайлОжидается
Каждый тип, который принимает форма, в виде настоящего файла этого типаallowed_jpg.jpg, allowed_png.png, allowed_pdf.pdfaccept
Тип, который форма не принимаетdenied.svg, denied.html, denied.exe, denied.shreject extension_rule
Расширение говорит об одном типе, а содержимое другого, например PDF с именем .jpgpdf_as_jpg.jpg, png_as_pdf.pdf, jpg_as_png.pngreject mime_mismatch
Два расширения, последнее не разрешеноinvoice.jpg.exereject extension_rule
Расширения нет совсемinvoiceunspecified extension_rule
Расширение заглавными буквамиPHOTO.JPGunspecified extension_rule

Файл SVG или HTML, принятый за изображение или простой текст, позволяет провести скрипт через форму. Поэтому они в списке типов, которые нужно отклонять, если ваша форма не должна их принимать.

Содержимое

Открывает ли система файл или смотрит только на имя?

Тест-кейсФайлОжидается
Файл, обрезанный так, как его оставляет прерванная загрузкаcorrupt-truncate.pdfreject content_malformed
Файл, первые байты которого - нули, так что ничто не говорит, что это за файлcorrupt-zero-head.pngreject content_malformed
Самый маленький файл, который допускает формат, корректный и крошечныйtfg generate --preset empty-and-minimalaccept

Файл, у которого правильные только имя и размер, проходит любую проверку, которая его не открывает. Повреждённые примеры файлов есть в форматах PDF, Word, Excel, PowerPoint, JPG, PNG, MP4 и ZIP, а на странице Повреждённые тестовые файлы описано, как сделать их в любом формате и любого размера.

Имя

Возвращается ли файл под тем именем, которое ему дали?

Тест-кейсФайлОжидается
Пробелы и скобкиmy report (final) v2.jpgaccept
Буквы вне ASCII и эмодзиwiadomość_日本語_🎉.jpgunspecified filename_invalid
Имя длиннее 200 символовaaa...aaa.jpgunspecified filename_too_long
Имя, которое выбирается из своей папки, ../ или ..\climbing_name.jpg, загружается как ../tfg_climbed_out.jpgunspecified filename_traversal
Абсолютный путь, в Linux или Windowsabsolute_name.jpg, загружается как /tmp/tfg_climbed_out.jpgunspecified filename_traversal

Имя с путём нельзя сохранить на диск, поэтому у файла обычное имя, а манифест говорит, под каким именем его загрузить. Принять файл и оставить только последнюю часть имени - хороший ответ. Записать его за пределы папки загрузки - тот дефект, ради которого этот кейс и существует. Пресет filename-handling содержит гораздо больше имён: похожие друг на друга буквы, невидимые символы, имена, зарезервированные Windows, и длины, которые считаются в байтах.

Тест-кейсФайлОжидается
Пятьдесят файлов в одной загрузкеот bulk_0001.jpg до bulk_0050.jpgaccept
ZIP, в котором действительно 200 документовtfg generate --format zip --size 5mb --set entries=200 --set entry_format=pdfaccept

В тесте

Запуск списка как теста

Манифест содержит ожидаемый результат для каждого файла и имя, под которым его загружать, поэтому один цикл проходит весь список: 

import json, os

directory = "upload"
manifest = json.load(open(os.path.join(directory, "manifest.json")))

for entry in manifest["files"]:
    outcome = entry["expected"]["outcome"]
    if outcome == "unspecified":
        continue
    name = entry.get("send_as", entry["name"])
    response = upload(os.path.join(directory, entry["path"]), name)
    assert response.ok == (outcome == "accept"), name

Файлы с пометкой unspecified здесь пропускаются, потому что ответ для них - ваша собственная политика. Примите решение, запишите его в рецепт через expected, и цикл проверит и их. Тестовые файлы в CI показывают, как запустить это в конвейере.
