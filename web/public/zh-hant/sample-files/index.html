測試用範例檔案

可直接下載的真實檔案，用來測試上傳表單、剖析器或匯入功能：本產生器能寫出的每種格式各一個檔案、刻意弄壞的檔案、依試算表程式的匯出方式寫成的表格，以及佔位圖片。無需安裝，也無需註冊。

由一個配方產生

本頁所有檔案都來自同一個配方 samples.yaml。用 tfg 執行它，在任何電腦上都會得到相同的位元組，所以每個檔案旁邊的 SHA-256 是你可以自己核對的，而不是只能相信的。 

tfg generate samples.yaml --out samples

所有總和檢查碼都在 SHA256SUMS 中。把它放進那個資料夾，tfg tool checksum-check samples/SHA256SUMS 或 sha256sum -c SHA256SUMS 就會告訴你每個檔案是否相符。

每張表的最後一欄，是清單期望你的系統如何處理該檔案。accept 表示應該接受，reject 表示應該拒絕，unspecified 表示取決於你的系統規則。

每種格式

每種格式一個檔案，每個 1 MB

文件、圖片、文字、資料、壓縮檔、郵件、遙測、音訊和影片，每個都恰好 1048576 位元組，而且都是該格式的真實檔案。PDF 能在 PDF 閱讀器中開啟，DOCX 能在 Word 中開啟，XLSX 能在 Excel 中開啟，ZIP 能解壓縮。伺服器會以壓縮形式傳送文字檔和部分圖片，所以下載時瀏覽器顯示的大小可能比表中的小。儲存下來的檔案大小與表中一致，SHA-256 也相符。

刻意損毀

損毀的 PDF、Word、Excel 檔案，以及圖片、影片和 ZIP

每個檔案都先以完好狀態產生，然後被弄壞，大小仍然恰好是 1 MB。truncate 像中斷的上傳那樣截掉結尾，zero-head 用零覆蓋開頭的位元組，而讀取器正是靠這些位元組判斷檔案是什麼。清單期望你的系統拒絕其中每一個。

corrupt-truncate.docx truncate 1 048 576 B 6a33277ee3cdaba8 reject
corrupt-truncate.xlsx truncate 1 048 576 B f81302c89c0f1367 reject
corrupt-truncate.pptx truncate 1 048 576 B fc28544bdb91bc61 reject
corrupt-truncate.jpg truncate 1 048 576 B a8e75174cb1b61c2 reject
corrupt-zero-head.png zero-head 1 048 576 B d96c7cdea35c8c28 reject

用於匯入

CSV、JSON 和 Excel 表格

從這裡去哪裡
