預設集

圖片尺寸

我的系統能接受螢幕和平台所用尺寸的圖片嗎？

picture-sizes 預設集用一個指令為這個問題建立出整組真實測試檔案，並在旁邊放一個 manifest.json，說明你的系統應如何回應每個檔案。以下所有內容都依此版本的預設值從程式中讀取。

它通常能發現什麼？

  • 依一種形狀設定的寬度或高度上限拒絕了另一種形狀，例如寬 1584 px 的個人檔案背景
  • 程式碼以為是橫向圖片，來的卻是直向圖片，於是縮圖被裁切或壓扁
  • 高度為奇數的圖片，例如 1200 x 627，被只接受偶數尺寸的步驟拒絕
  • 檔案本身很小，產生縮圖時卻耗盡時間或記憶體的 4K 圖片

組合裡有什麼？

使用預設值時，如 tfg preset show picture-sizes 所回報的：

檔案數21
其配方中的 target 數21
總大小4 178 420 B
格式jpg

以及該組合的清單對你的系統有何預期：

預期意義檔案數
accept你的系統應該接受這個檔案。21

你可以變更什麼？

設定接受預設值作用
--groups 以逗號分隔的組名，或 all all 組合包含哪些尺寸：screens 代表螢幕尺寸，avatars 代表頭像，social 代表封面、橫幅、貼文和縮圖。填 all 代表全部。
--content placeholder, test test 圖片顯示什麼。測試圖樣用來檢查檔案如何被讀取。佔位圖是中間有文字的純色圖片，用來在真實圖片出現之前排版頁面。
--format 格式頁面中的格式 id jpg 組合中每個檔案的格式。它是工具本身的參數，預設集只是給它一個預設值。

如何執行？

查看組合的開銷、建置它，或取出它的配方來編輯：

tfg preset show picture-sizes
tfg generate --preset picture-sizes --out ./picture-sizes
tfg preset eject picture-sizes > picture-sizes.yaml

也可以在你自己的配方中以它為基礎，放在測試旁邊：

version: 1
extends: preset:picture-sizes
