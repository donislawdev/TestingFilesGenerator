Documentação

Checar um arquivo compactado antes de descompactá-lo e conferir somas de verificação

Além do gerador, tfg tem pequenas ferramentas para arquivos que você já tem: se um arquivo compactado é seguro para descompactar, e se um arquivo ou uma pasta inteira ainda é o que diz a sua soma de verificação. Elas rodam na sua máquina, sem upload e sem conta.

A resposta curta

tfg tool archive-scan download.zip lê o arquivo compactado sem descompactar nada e termina com o código 0 quando ele é seguro, ou 7 com uma lista do que encontrou. tfg tool checksum setup.exe --expected <sum> diz se um arquivo confere com a soma que uma página de download informou.

O que existe

Quais ferramentas existem?

Esta é a lista que o programa imprime, lida dele quando esta página é construída. tfg tool list imprime a mesma, e tfg tool show <id> diz o que cada uma aceita. Cada ferramenta também está na tela Tools da janela, com as mesmas configurações.

Ferramenta O que responde
archive-scan Este arquivo compactado é seguro para descompactar?
checksum Este arquivo é mesmo o que diz ser?
checksum-check Cada arquivo ainda é o que diz o seu arquivo de somas de verificação?
checksum-write Como vou saber depois que nenhum destes arquivos mudou?

Arquivos compactados

Este arquivo compactado é seguro para descompactar? Zip slip e zip bombs

archive-scan olha dentro de um arquivo ZIP, TAR, TAR.GZ ou gzip sem gravar nada em disco e diz se descompactá-lo é seguro. Ele aponta:

  • uma entrada que seria gravada fora da pasta, a armadilha conhecida como zip slip
  • um link, um dispositivo, ou dois nomes que cairiam no mesmo arquivo
  • um nome que um sistema não consegue gravar
  • uma entrada feita para explodir ao ser descompactada, a armadilha conhecida como zip bomb
  • uma entrada danificada

Arquivos compactados dentro do arquivo compactado, como um ZIP dentro de um ZIP ou um DOCX dentro de um TAR, são lidos do mesmo jeito, na memória, até 16 níveis de profundidade. Uma armadilha em um deles é uma armadilha no todo, porque um programa que descompacta tudo descompacta esses também. 

tfg tool archive-scan upload.zip
tfg tool archive-scan backup.tar.gz --unpacked_limit 500mb

--unpacked_limit também aponta um arquivo compactado que, descompactado, ocupa mais do que você permite. Se for seguro, termina com o código 0, e se encontrar algo, com 7, então um pipeline pode parar aí.

Um arquivo

Este arquivo é mesmo o que diz ser?

checksum calcula a soma de verificação de um arquivo e, se você der uma para comparar, diz se elas batem. Aceita md5, sha1, sha256, sha512 e crc32, sha256 se você não pedir outra, e reconhece pelo comprimento qual delas você deu. 

tfg tool checksum installer.msi
tfg tool checksum installer.msi --expected 9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08

Uma soma que não bate termina com o código 7. Responde à mesma pergunta que Get-FileHash no Windows ou sha256sum no Linux, com a comparação feita para você.

Uma pasta inteira

Alguma coisa mudou nesta pasta?

checksum-write grava a soma de verificação de cada arquivo de uma pasta em um SHA256SUMS ao lado deles, com os mesmos bytes que o sha256sum grava, e nunca por cima de um que já exista. checksum-check depois confere cada arquivo que o SHA256SUMS lista. 

tfg tool checksum-write ./fixtures
tfg tool checksum-check ./fixtures/SHA256SUMS

Arquivos que ele não lista não são examinados, como no sha256sum -c, e um caminho que sai da pasta é recusado em vez de lido. Os arquivos de exemplo vêm com um SHA256SUMS que você pode conferir assim.
