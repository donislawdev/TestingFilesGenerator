Presets

Tamanhos de imagem

Meu sistema aceita imagens nos tamanhos que telas e plataformas usam?

O preset picture-sizes monta com um único comando um conjunto inteiro de arquivos de teste reais para esta pergunta, e um manifest.json ao lado dizendo como seu sistema deve reagir a cada arquivo. Tudo abaixo é lido do programa, com os valores padrão desta versão.

O que ele costuma encontrar?

  • um limite de largura ou altura pensado para um formato de imagem que recusa outro, como um fundo de perfil com 1584 px de largura
  • uma miniatura cortada ou achatada porque o código espera uma imagem horizontal e chega uma vertical
  • uma imagem de altura ímpar, como 1200 x 627, recusada por uma etapa que só aceita tamanhos pares
  • uma imagem 4K que fica sem tempo ou sem memória a caminho de uma miniatura, embora o arquivo seja pequeno

O que há no conjunto?

Com os valores padrão, como o tfg preset show picture-sizes informa:

Arquivos21
Targets na sua receita21
Tamanho total4 178 420 B
Formatosjpg

E o que o manifesto desse conjunto espera do seu sistema:

EsperadoSignificadoArquivos
acceptSeu sistema deve aceitar o arquivo.21

O que você pode mudar?

ConfiguraçãoAceitaPadrãoO que faz
--groups nomes de grupo separados por vírgulas, ou all all Quais tamanhos o conjunto contém: screens para tamanhos de tela, avatars para fotos de perfil e social para capas, banners, publicações e miniaturas. Deixe em all para ter todos.
--content placeholder, test test O que a imagem mostra. Um padrão de teste serve para verificar como um arquivo é lido. Um espaço reservado é uma cor lisa com texto no meio, para montar uma página antes de existirem as imagens reais.
--format um id de formato da página de formatos jpg O formato de cada arquivo do conjunto. É uma opção da própria ferramenta, e o preset apenas dá a ela um valor padrão.

Como executar?

Veja quanto o conjunto custaria, monte-o ou pegue a receita dele para editar:

tfg preset show picture-sizes
tfg generate --preset picture-sizes --out ./picture-sizes
tfg preset eject picture-sizes > picture-sizes.yaml

Ou construa sobre ele em uma receita sua, ao lado dos seus testes:

version: 1
extends: preset:picture-sizes
