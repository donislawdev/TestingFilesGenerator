문서

tfg 설치 방법, 첫 테스트 파일 만들기, 그리고 프로그램이 받고 쓰는 모든 것. 모든 명령과 플래그, 레시피의 모든 키, 매니페스트의 모든 필드, 모든 형식의 모든 설정을 다룹니다. 이 페이지들은 영어로 되어 있습니다. 사이트를 만들 때마다 프로그램 자체에서 생성되므로 내려받는 버전이 하는 일과 항상 일치합니다.

문서 페이지

  • 설치 EN

    Windows, macOS, Linux용으로 내려받고 압축 파일을 확인하거나 Docker, npm, pip, Go로 설치합니다.

  • 시작하기 EN

    정확한 크기의 첫 파일, 이어서 만 개의 파일을 만들고 확인하고 지운 뒤 레시피로 남깁니다.

  • 명령 EN

    모든 명령과 모든 플래그, 그 기본값, 그리고 모든 종료 코드.

  • 레시피 작성 EN

    레시피의 모든 키, 크기, 파일 이름, 기대 반응, 손상, 압축 파일, 프리셋.

  • 레시피 모음 EN

    업로드, 가져오기, 압축 파일, 이메일, 미디어, CI, 대량 파일을 위해 바로 내려받을 수 있는 레시피.

  • 매니페스트 EN

    manifest.json의 모든 필드와 테스트에서 읽는 방법.

  • 형식 설정 EN

    모든 형식의 모든 설정과 허용되는 값, 기본값.

  • 테스트 프레임워크 EN

    pytest, Playwright, Vitest, node:test 안에서 파일을 쓰는 방법.

  • 데스크톱 앱 EN

    프로그램 창을 화면별로 설명합니다.

  • 도구

    이미 가진 파일을 위한 오프라인 도구. zip slip과 zip 폭탄을 포함해 아카이브를 안전하게 풀 수 있는지 보고, SHA-256 체크섬을 확인하거나 만듭니다.

이 도구가 하는 일, 주제별

  • 형식

    이 생성기가 만드는 모든 파일 형식, 형식별 가능한 가장 작은 파일, 각 형식이 받는 설정. 32종 모두 해당 소프트웨어에서 열립니다.

  • 프리셋

    기성 테스트 파일 세트로, 각 세트가 하나의 테스트 질문에 답합니다. 업로드 한도, 파일 이름, 인코딩, 표 가져오기, 빈 파일, 업로드 검증.

  • 손상 파일

    일부러 망가뜨린, 크기가 정확한 파일. 시스템이 거부해야 함을 알리는 매니페스트가 딸려 옵니다. 업로드 검증과 파서 테스트용.

  • 샘플 파일

    테스트용 샘플 파일 다운로드. 모든 형식의 1MB 파일, 손상된 PDF, Word, Excel 파일, CSV 표, 자리 표시자 이미지를 SHA-256과 함께 제공합니다.

  • 업로드 테스트 케이스

    파일 업로드 테스트 케이스. 크기 한도, 빈 파일과 손상된 파일, 잘못된 유형, 예상하지 못한 파일 이름, 아카이브까지 케이스마다 확인할 파일이 있습니다.

  • CI의 테스트 파일

    바이너리를 커밋하는 대신 파이프라인에서 테스트 파일을 생성하세요. GitHub Actions 워크플로, GitLab 작업, 종료 코드, PowerShell의 함정.

  • 정확한 크기

    fsutil, dd, truncate, mkfile을 각 시스템에서 직접 측정했으며, 테스트에 PDF나 PNG가 필요할 때 이렇게 만든 파일로 부족한 이유도 설명합니다.

아직 막히셨나요?

tfg <command> --help 명령은 터미널에서 해당 명령이 받는 값을 보여 줍니다. 거부될 때는 항상 어떤 설정 때문인지, 이유, 그리고 사용할 수 있는 값을 알려 줍니다. 페이지 설명과 다르게 동작하면 알려 주세요. 그것은 페이지나 프로그램의 버그입니다.
