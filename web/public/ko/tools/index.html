문서

압축을 풀기 전에 아카이브를 검사하고 체크섬 확인하기

tfg에는 생성기 외에도 이미 가진 파일을 위한 작은 도구가 있습니다. 아카이브를 안전하게 풀 수 있는지, 파일이나 폴더 전체가 체크섬이 말하는 그대로인지 확인합니다. 업로드도 계정도 없이 여러분의 컴퓨터에서 실행됩니다.

짧은 답

tfg tool archive-scan download.zip은 아무것도 풀지 않고 아카이브를 읽어, 안전하면 코드 0으로, 아니면 발견한 내용의 목록과 함께 코드 7로 끝납니다. tfg tool checksum setup.exe --expected <sum>은 파일이 다운로드 페이지에 적힌 체크섬과 일치하는지 알려 줍니다.

있는 것

어떤 도구가 있나요?

이것은 프로그램이 출력하는 목록이며, 이 페이지를 빌드할 때 프로그램에서 읽어 옵니다. tfg tool list는 같은 목록을 출력하고, tfg tool show <id>는 그중 하나가 받는 설정을 알려 줍니다. 모든 도구는 데스크톱 창의 도구 화면에도 같은 설정으로 있습니다.

도구 답하는 질문
archive-scan 이 아카이브를 안전하게 풀 수 있을까요?
checksum 이 파일이 주장하는 바로 그 파일일까요?
checksum-check 모든 파일이 아직 체크섬 파일에 적힌 그대로일까요?
checksum-write 이 파일들 중 어느 것도 바뀌지 않았다는 것을 나중에 어떻게 알 수 있을까요?

아카이브

이 아카이브를 안전하게 풀 수 있나요? zip slip과 zip 폭탄

archive-scan은 디스크에 아무것도 쓰지 않고 ZIP, TAR, TAR.GZ, gzip 파일 안을 살펴보고, 압축을 풀어도 안전한지 알려 줍니다. 보고하는 것은 다음과 같습니다.

  • 폴더 밖에 쓰이게 될 항목. zip slip이라고 불리는 함정입니다
  • 링크, 장치, 또는 한 파일에 겹쳐 쓰이게 될 두 이름
  • 시스템이 쓸 수 없는 이름
  • 압축을 풀면 폭발적으로 커지도록 만든 항목. zip 폭탄이라고 불리는 함정입니다
  • 손상된 항목

ZIP 안의 ZIP이나 TAR 안의 DOCX처럼 아카이브 안의 아카이브도 같은 방식으로 메모리에서 16단계 깊이까지 읽습니다. 그중 하나에 있는 함정은 전체의 함정입니다. 모든 것을 푸는 프로그램은 그것들도 풀기 때문입니다. 

tfg tool archive-scan upload.zip
tfg tool archive-scan backup.tar.gz --unpacked_limit 500mb

--unpacked_limit를 주면 풀었을 때 허용한 크기보다 커지는 아카이브도 보고합니다. 안전하면 코드 0, 무언가 발견하면 코드 7로 끝나므로 파이프라인이 거기서 멈출 수 있습니다.

파일 하나

이 파일이 주장하는 바로 그 파일인가요?

checksum은 파일의 체크섬을 계산하고, 비교할 값을 주면 일치하는지 알려 줍니다. md5, sha1, sha256, sha512, crc32를 지원하고, 따로 지정하지 않으면 sha256을 쓰며, 주어진 값이 어느 종류인지는 길이로 알아냅니다. 

tfg tool checksum installer.msi
tfg tool checksum installer.msi --expected 9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08

일치하지 않는 체크섬은 코드 7로 끝납니다. Windows의 Get-FileHash나 Linux의 sha256sum과 같은 질문에 답하되, 비교까지 대신 해 줍니다.

폴더 전체

이 폴더에서 바뀐 것이 있나요?

checksum-write는 폴더 안 모든 파일의 체크섬을 파일들 옆의 SHA256SUMS에 씁니다. sha256sum이 쓰는 것과 같은 바이트이며, 이미 있는 SHA256SUMS를 덮어쓰지 않습니다. checksum-check는 나중에 SHA256SUMS에 나열된 모든 파일을 확인합니다. 

tfg tool checksum-write ./fixtures
tfg tool checksum-check ./fixtures/SHA256SUMS

나열되지 않은 파일은 sha256sum -c와 마찬가지로 확인하지 않으며, 폴더 밖으로 나가는 경로는 읽지 않고 거부합니다. 샘플 파일에는 이렇게 확인할 수 있는 SHA256SUMS가 함께 있습니다.
