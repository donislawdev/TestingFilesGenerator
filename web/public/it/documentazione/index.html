Documentazione

Come installare tfg, creare i primi file di test e tutto ciò che il programma accetta e scrive: ogni comando e ogni opzione, ogni chiave di una ricetta, ogni campo del manifest e ogni impostazione di ogni formato. Queste pagine sono in inglese, perché vengono prodotte dal programma stesso a ogni costruzione del sito, e dicono quindi sempre ciò che fa la versione che scarichi.

Che cosa fa lo strumento, argomento per argomento

  • Formati

    Tutti i formati che il generatore produce, il file più piccolo possibile per ciascuno e le impostazioni che accetta. Tutti i 32 si aprono nel loro programma.

  • Preset

    Set pronti di file di test, ognuno risponde a una domanda: limiti di upload, nomi dei file, codifiche, importazione di tabelle, file vuoti e validazione.

  • File corrotti

    Un file rotto di proposito, della dimensione esatta, con un manifest che dice che il tuo sistema deve rifiutarlo. Per testare validazione degli upload e parser.

  • File di esempio

    File di test e di esempio da scaricare: ogni formato da 1 MB, PDF, Word ed Excel corrotti, tabelle CSV e immagini segnaposto, ognuno con il suo SHA-256.

  • Casi di test upload

    Casi di test per l'upload di file: limite di dimensione, file vuoti e corrotti, tipo sbagliato, nomi inattesi e archivi, ognuno con il file che lo verifica.

  • File di test in CI

    Genera file di test nella pipeline invece di committare binari: workflow GitHub Actions, job GitLab, codici di uscita e la trappola di PowerShell.

  • Dimensione esatta

    fsutil, dd, truncate e mkfile, ciascuno misurato sul proprio sistema, e perché un file fatto così non è un PDF né un PNG quando un test ne richiede uno.

Ancora bloccato?

tfg <command> --help mostra nel terminale che cosa accetta un comando. Ogni rifiuto nomina l'impostazione a cui si riferisce, il motivo e un valore che funzionerebbe. Se qualcosa non si comporta come dice una pagina, segnalalo. È un errore della pagina o del programma.
