Presetări

Dimensiuni de imagine

Acceptă sistemul meu imagini la dimensiunile folosite de ecrane și platforme?

Presetarea picture-sizes construiește cu o singură comandă un set întreg de fișiere de test reale pentru această întrebare, și un manifest.json alături care spune cum trebuie să reacționeze sistemul tău la fiecare fișier. Tot ce urmează este citit din program, la valorile implicite ale acestei versiuni.

Ce găsește de obicei?

  • o limită de lățime sau de înălțime gândită pentru o formă care respinge alta, de exemplu un fundal de profil lat de 1584 px
  • o miniatură tăiată sau turtită pentru că codul așteaptă o imagine orizontală și sosește una verticală
  • o imagine cu înălțime impară, de exemplu 1200 x 627, respinsă de un pas care acceptă doar dimensiuni pare
  • o imagine 4K care rămâne fără timp sau fără memorie în drum spre o miniatură, deși fișierul în sine este mic

Ce este în set?

La valorile implicite, așa cum le raportează tfg preset show picture-sizes:

Fișiere21
Targeturi în rețeta lui21
Dimensiune totală4 178 420 B
Formatejpg

Și ce așteaptă manifestul acelui set de la sistemul tău:

AșteptatSemnificațieFișiere
acceptSistemul tău trebuie să accepte fișierul.21

Ce poți schimba?

SetarePrimeșteImplicitCe face
--groups nume de grupuri separate prin virgule, sau all all Ce dimensiuni conține setul: screens pentru dimensiunile ecranelor, avatars pentru fotografiile de profil și social pentru coperte, bannere, postări și miniaturi. Lasă all pentru toate.
--content placeholder, test test Ce arată imaginea. Un model de test servește la verificarea felului în care este citit un fișier. Un substituent este o culoare uniformă cu text în mijloc, pentru a așeza o pagină înainte să existe imaginile reale.
--format un id de format din pagina de formate jpg Formatul fiecărui fișier din set. Este o opțiune a instrumentului însuși, iar presetarea îi dă doar o valoare implicită.

Cum o rulezi?

Vezi cât ar costa setul, construiește-l sau ia-i rețeta ca s-o editezi:

tfg preset show picture-sizes
tfg generate --preset picture-sizes --out ./picture-sizes
tfg preset eject picture-sizes > picture-sizes.yaml

Sau construiește peste ea într-o rețetă proprie, lângă testele tale:

version: 1
extends: preset:picture-sizes
