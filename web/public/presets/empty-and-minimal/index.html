Presets

Empty and minimal

Does a file that is valid and as small as the format allows get through?

The empty-and-minimal preset builds a whole set of real test files for this question in one command, and a manifest.json beside them saying how your system should react to each file. Everything below is read from the program, at the defaults of this version.

What does it usually find?

  • a valid file turned away for being too small, where the check counts bytes instead of reading them
  • an empty file that brings the reader down rather than being reported
  • a picture one pixel wide that divides by zero on the way to a thumbnail
  • storage that reads nought bytes as a failed upload and keeps retrying

What can you change?

SettingTakesDefaultWhat it does
--formats format ids separated by commas, or all all Which formats the set is built from. Leave it at all for every format this build has, or name the ones your system accepts.

How do you run it?

See what the set would cost, build it, or take its recipe to edit:

tfg preset show empty-and-minimal
tfg generate --preset empty-and-minimal --out ./empty-and-minimal
tfg preset eject empty-and-minimal > empty-and-minimal.yaml

Or build on it in a recipe of your own, next to your tests:

version: 1
extends: preset:empty-and-minimal
